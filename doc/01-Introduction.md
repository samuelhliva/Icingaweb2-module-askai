# Introduction

## Overview

The AskAI module for Icinga Web 2 provides AI-powered assistance for monitoring and troubleshooting tasks. It integrates artificial intelligence capabilities directly into your Icinga monitoring interface, helping you analyze issues, understand alerts, and get recommendations for problem resolution.

## Key Features

* **Intelligent Alert Analysis**: Get AI-powered insights into monitoring alerts and their potential causes
* **Contextual Assistance**: Receive recommendations based on your specific monitoring environment
* **Integration with Icinga**: Seamlessly integrated into the Icinga Web 2 interface

## Use Cases

* Quickly understand complex alert scenarios
* Get troubleshooting suggestions for monitoring issues
* Learn about monitoring best practices
* Analyze patterns in your infrastructure health

## Requirements

* Icinga Web 2 (>= 2.9.0)
* PHP (>= 7.2)
* Access to an AI service provider (configuration required)
